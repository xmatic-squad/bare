# Открытые вопросы

Решения по этим пунктам ещё не приняты. Каждое принятое решение уходит в ADR и вычёркивается отсюда.

- Регистрация: открытая или по инвайтам?
- Механика добавления контакта и приглашения в комнату: по нику? по ссылке?
- Лимиты: длина сообщения, rate limiting, антиспам.
- Смена пароля (= перешифровка ключевого блоба): в v1 или позже?
- Идентификация устройства для per-device очередей.
- Язык интерфейса (ru/en); нужна ли i18n.
- Визуальная айдентика: отдельный бриф будет добавлен в `docs/identity/`.
